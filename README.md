# Kova

Kova is a private-beta Windows application and web interface for configuring and managing ARK: Survival Ascended dedicated servers.

This repository provides public project information. The application source code is not published here.

## Project features

* Server configuration tools with Game.ini and GameUserSettings.ini output.
* Separate settings and mod lists for each server map.
* Copying selected mod IDs between server profiles.
* Local server installation and INI file management through the Windows application.
* Engram, item stack, and breeding configuration tools.

## Planned CurseForge integration

We are applying for CurseForge API access to support in-app ASA mod searches and display project names, IDs, descriptions, author credits, and links to official CurseForge pages.

The integration is intended for mod discovery and metadata. Kova will not rehost mod files or provide an alternative mod download service.

API credentials will remain on the backend and will not be exposed in the desktop application. Initial usage will consist of occasional searches by two private-beta users.
